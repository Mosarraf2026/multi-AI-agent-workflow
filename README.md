# Multi-AI Agent Automation

This repository showcases a custom-built, fully autonomous multi-AI agent workflow designed to streamline business operations and eliminate manual data entry.

## Overview
The system integrates various platforms to automate end-to-end business workflows. It saves up to 20 hours of manual work per week by managing complex tasks in a single loop.

## Key Features
*   **Content Creation:** Uses Google Gemini AI to generate high-quality LinkedIn posts.
*   **Lead Qualification:** Automatically qualifies leads and processes them instantly.
*   **CRM Integration:** Syncs processed data directly into HubSpot CRM.
*   **Email Outreach:** Sends personalized, automated email updates to stakeholders.
*   **Centralized Data:** Manages all inputs and triggers through Google Sheets.

## How It Works
1.  **Trigger:** User enters topics into Google Sheets.
2.  **Processing:** Multiple AI agents work in parallel to generate content and qualify leads.
3.  **Output:** Automated publishing to LinkedIn and data sync to HubSpot and Gmail.

## Tools Used
*   Make.com
*   Google Gemini AI
*   Google Sheets
*   HubSpot CRM
*   LinkedIn API
